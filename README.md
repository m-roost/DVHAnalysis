# Overview


DVH Analysis is a C# WPF program based on Varian Eclipse Scripting API (ESAPI). It works as a binary script plugin and can calculate, display, and save various DVH metrics for opened plans/plansums in Varian Eclipse treatment planning system.

- For developers trying to compile and deploy the script, see [Developer_Guide.md](./Doc/Developer_Guide.md)

- User guide in how to use the script can be found here [DVHAnalysisScript.pdf](./dvhanalysisgui/resources/DVHAnalysisScript.pdf)

- For change log in recent versions, see [Version_Tracking.md](./Doc/Version_Tracking.md)
